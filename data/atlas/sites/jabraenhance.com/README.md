# jabraenhance.com

Live Jabra Enhance brand site (US online OTC hearing aids): catalog at /product lists three models (Select M3, M2, M1) on server-rendered pages with user guide PDFs on cdn.jabraenhance.com; older models (700, 500, 300, 50R, discontinued 200/100/50) appear only in /start guides and comparison pages. [1] [2] [3] [4]

## What this site is and whose

- Jabra Enhance sells FDA-cleared self-fitting OTC hearing aids online, with 3 years of virtual audiology included. [5] [6]
- Homepage prices: Select M3 $1,695 (was $1,995), M2 $1,695, M1 $1,195. [6]
- Phone support (800) 854-2772; financing via Bread Pay. [6]

## Structure

- robots.txt lists five sitemaps: sitemap.xml (index), sitemap-products.xml, blog/sitemap.xml, copp/sitemap.xml, copp/sitemap-accessories.xml; the index also lists sitemap-0.xml. [7] [8]
- sitemap-products.xml lists only the three model pages /product/enhanceselectm3, m2 and m1. [2]
- /product/{slug} also holds comparison pages such as m3-vs-500, 700-vs-100 (11 in the sitemap sections besides the models), which are not model pages. [9] [10]
- Accessories live at /accessories/{slug} (18 pages) with prices, e.g. Charging Case $250, TV Streamer $299. [11]
- Quick-start guides at /start/enhance-select-{50,50r,100,200,300,500,700}, each with /basics, /charge, /connect subpages. [3] [12]

## Catalog, support, documents and apps

- Catalog: https://www.jabraenhance.com/product (ItemList JSON-LD); model pages /product/enhanceselectm1|m2|m3 (ProductGroup JSON-LD). [1] [13]
- User guide PDFs: cdn.jabraenhance.com/shared/userguides/enhance-select-m1.pdf, m2.pdf, m3.pdf, linked from /help and model pages. [4] [13]
- Getting-started PDFs on sound-files.jabraenhance.com for devices bought before 12/13/21. [3]
- Support: /help, /faq and the help.jabraenhance.com knowledge base. [4] [14]
- App: Jabra Enhance Select, iOS id 1502033340, Android com.lively.app. [13] [15]
- /start marks Enhance Select 200, 100 and 50 as Discontinued; 700, 500, 300, 50R are listed without that label. [3]

## Rendering and quirks

- Catalog and model pages need no scripts to show content (needsRender false). [1] [13]
- /contact-us, /start, /survey and /compatibility are flagged as needing render. [16] [3] [17] [18]
- robots.txt disallows /purchase, /cart, /refer, /account, /schedule, /getapp and some accessory pages; /refer was skipped for that reason. [7]
